# Email Explorer — മലയാളം

പൂർണമായും Cloudflare Workers-ൽ പ്രവർത്തിക്കുന്ന ഒരു വെബ്‌മെയിൽ.

ഈ റിപ്പോസിറ്ററി G4brym/email-explorer (MIT ലൈസൻസ്) ന്റെ ബഹുഭാഷാ ഫോർക്ക് ആണ്.

ഈ ഇന്റർഫേസ് 73 ഭാഷകളിൽ ലഭ്യമാണ്. വലതു മുകളിൽ നിന്ന് നിങ്ങളുടെ ഭാഷ തിരഞ്ഞെടുക്കുക; തിരഞ്ഞെടുപ്പ് ബ്രൗസറിൽ സൂക്ഷിക്കും.
