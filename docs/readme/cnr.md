# Email Explorer — Crnogorski

Veb klijent za e-poštu koji radi u cjelosti na Cloudflare Workers.

Ovaj repozitorijum je višejezični fork projekta G4brym/email-explorer (MIT licenca).

Interfejs je dostupan na 72 jezika. Izaberite svoj gore desno; izbor se pamti u pregledaču.
