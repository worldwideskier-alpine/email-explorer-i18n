# Email Explorer — ગુજરાતી

સંપૂર્ણપણે Cloudflare Workers પર ચાલતું વેબમેલ.

આ રિપોઝિટરી G4brym/email-explorer (MIT લાઇસન્સ) નો બહુભાષી ફોર્ક છે.

આ ઇન્ટરફેસ 46 ભાષાઓમાં ઉપલબ્ધ છે. ઉપર જમણી બાજુથી તમારી ભાષા પસંદ કરો; પસંદગી બ્રાઉઝરમાં સચવાય છે.
