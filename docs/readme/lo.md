# Email Explorer — ລາວ

ເວັບເມວທີ່ເຮັດວຽກຢູ່ເທິງ Cloudflare Workers ທັງໝົດ.

ບ່ອນເກັບນີ້ແມ່ນ fork ຫຼາຍພາສາຂອງ G4brym/email-explorer (ໃບອະນຸຍາດ MIT).

ໜ້າຈໍໃຊ້ງານມີ 72 ພາສາ. ເລືອກພາສາຂອງທ່ານຢູ່ມຸມຂວາເທິງ; ການເລືອກຈະຖືກຈື່ໄວ້ໃນໂປຣແກຣມທ່ອງເວັບ.
