# Email Explorer — فارسی

یک وب‌میل که به‌تمامی روی Cloudflare Workers اجرا می‌شود.

این مخزن انشعابی چندزبانه از G4brym/email-explorer (پروانهٔ MIT) است.

رابط کاربری به ۷۳ زبان در دسترس است. زبانتان را از بالا سمت راست برگزینید؛ انتخاب در مرورگر می‌ماند.
