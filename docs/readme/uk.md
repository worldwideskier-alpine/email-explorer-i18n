# Email Explorer — Українська

Вебклієнт електронної пошти, який працює цілком на Cloudflare Workers.

Цей репозиторій — багатомовний форк G4brym/email-explorer (ліцензія MIT).

Інтерфейс доступний 73 мовами. Оберіть свою у верхньому правому куті; вибір зберігається у браузері.
