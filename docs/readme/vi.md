# Email Explorer — Tiếng Việt

Một ứng dụng thư điện tử trên web chạy hoàn toàn trên Cloudflare Workers.

Kho này là một nhánh đa ngôn ngữ của G4brym/email-explorer (giấy phép MIT).

Giao diện có sẵn bằng 73 ngôn ngữ. Hãy chọn ngôn ngữ của bạn ở góc trên bên phải; lựa chọn được ghi nhớ trong trình duyệt.
