# Email Explorer — Norsk bokmål

En nettbasert e-postklient som kjører helt på Cloudflare Workers.

Dette depotet er en flerspråklig fork av G4brym/email-explorer (MIT-lisens).

Grensesnittet finnes på 69 språk. Velg ditt oppe til høyre; valget huskes i nettleseren.
