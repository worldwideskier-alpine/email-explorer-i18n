# Email Explorer — Հայերեն

Վեբ փոստի հաճախորդ, որն ամբողջովին աշխատում է Cloudflare Workers-ի վրա։

Այս պահոցը G4brym/email-explorer-ի բազմալեզու պատառիկն է (MIT արտոնագիր)։

Միջերեսը հասանելի է 72 լեզվով։ Ընտրեք ձերը վերևի աջ անկյունում. ընտրությունը պահվում է դիտարկիչում։
