# Email Explorer — Magyar

Webes levelezőprogram, amely teljes egészében a Cloudflare Workers rendszerén fut.

Ez a tároló a G4brym/email-explorer (MIT licenc) többnyelvű forkja.

A felület 69 nyelven érhető el. Válassza ki a sajátját jobbra fent; a választás megmarad a böngészőben.
