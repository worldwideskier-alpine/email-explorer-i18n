# Email Explorer — ଓଡ଼ିଆ

ସମ୍ପୂର୍ଣ୍ଣ ଭାବରେ Cloudflare Workers ଉପରେ ଚାଲୁଥିବା ଏକ ୱେବମେଲ।

ଏହି ରିପୋଜିଟୋରୀ G4brym/email-explorer (MIT ଲାଇସେନ୍ସ) ର ବହୁଭାଷୀ ଫର୍କ।

ଏହି ଇଣ୍ଟରଫେସ୍ 46 ଟି ଭାଷାରେ ଉପଲବ୍ଧ। ଉପର ଡାହାଣରୁ ନିଜ ଭାଷା ବାଛନ୍ତୁ; ବଛାଟି ବ୍ରାଉଜରରେ ସାଇତା ହୋଇ ରହେ।
