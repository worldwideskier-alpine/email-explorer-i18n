# Email Explorer — Deutsch

Ein Webmail-Client, der vollständig auf Cloudflare Workers läuft.

Dieses Repository ist ein Fork von G4brym/email-explorer (MIT-Lizenz) zur Mehrsprachigkeit.

Die Oberfläche gibt es in 73 Sprachen. Wählen Sie Ihre oben rechts aus; die Auswahl wird im Browser gespeichert.
