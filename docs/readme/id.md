# Email Explorer — Bahasa Indonesia

Klien surel berbasis web yang berjalan sepenuhnya di Cloudflare Workers.

Repositori ini adalah fork multibahasa dari G4brym/email-explorer (Lisensi MIT).

Antarmukanya tersedia dalam 69 bahasa. Pilih bahasa Anda di kanan atas; pilihan itu disimpan di peramban.
