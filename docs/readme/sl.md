# Email Explorer — Slovenščina

Spletni odjemalec za e-pošto, ki v celoti teče na Cloudflare Workers.

To skladišče je večjezični fork projekta G4brym/email-explorer (licenca MIT).

Vmesnik je na voljo v 51 jezikih. Svojega izberite zgoraj desno; izbira se shrani v brskalniku.
