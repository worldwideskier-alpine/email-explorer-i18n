# Email Explorer — ਪੰਜਾਬੀ

ਪੂਰੀ ਤਰ੍ਹਾਂ Cloudflare Workers ਉੱਤੇ ਚੱਲਣ ਵਾਲਾ ਵੈੱਬਮੇਲ।

ਇਹ ਰਿਪੌਜ਼ਟਰੀ G4brym/email-explorer (MIT ਲਾਇਸੰਸ) ਦਾ ਬਹੁਭਾਸ਼ੀ ਫੋਰਕ ਹੈ।

ਇਹ ਇੰਟਰਫੇਸ 69 ਭਾਸ਼ਾਵਾਂ ਵਿੱਚ ਉਪਲਬਧ ਹੈ। ਉੱਪਰ ਸੱਜੇ ਪਾਸਿਓਂ ਆਪਣੀ ਭਾਸ਼ਾ ਚੁਣੋ; ਚੋਣ ਬ੍ਰਾਊਜ਼ਰ ਵਿੱਚ ਸਾਂਭੀ ਜਾਂਦੀ ਹੈ।
