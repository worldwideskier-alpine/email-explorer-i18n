# Email Explorer — Català

Un client de correu web que s'executa completament a Cloudflare Workers.

Aquest repositori és una bifurcació multilingüe de G4brym/email-explorer (llicència MIT).

La interfície està disponible en 69 idiomes. Trieu el vostre a dalt a la dreta; la tria es desa al navegador.
