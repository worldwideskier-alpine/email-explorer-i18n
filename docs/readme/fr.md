# Email Explorer — Français

Un client de messagerie web qui fonctionne entièrement sur Cloudflare Workers.

Ce dépôt est un fork multilingue de G4brym/email-explorer (licence MIT).

L'interface est disponible en 51 langues. Choisissez la vôtre en haut à droite ; votre choix est conservé dans le navigateur.
