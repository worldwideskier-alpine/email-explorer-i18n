# Email Explorer — Македонски

Веб-клиент за е-пошта што работи целосно на Cloudflare Workers.

Ова складиште е повеќејазичен форк на G4brym/email-explorer (MIT лиценца).

Интерфејсот е достапен на 69 јазици. Изберете го својот горе десно; изборот се памети во прелистувачот.
