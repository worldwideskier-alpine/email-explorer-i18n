# Email Explorer — ಕನ್ನಡ

ಸಂಪೂರ್ಣವಾಗಿ Cloudflare Workers ಮೇಲೆ ಚಲಿಸುವ ವೆಬ್‌ಮೇಲ್.

ಈ ರೆಪೊಸಿಟರಿ G4brym/email-explorer (MIT ಪರವಾನಗಿ) ಯ ಬಹುಭಾಷಾ ಫೋರ್ಕ್ ಆಗಿದೆ.

ಈ ಇಂಟರ್‌ಫೇಸ್ 46 ಭಾಷೆಗಳಲ್ಲಿ ಲಭ್ಯವಿದೆ. ಬಲ ಮೇಲ್ಭಾಗದಿಂದ ನಿಮ್ಮ ಭಾಷೆಯನ್ನು ಆರಿಸಿ; ಆಯ್ಕೆಯನ್ನು ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಉಳಿಸಲಾಗುತ್ತದೆ.
