# Email Explorer — Български

Уеб пощенски клиент, който работи изцяло върху Cloudflare Workers.

Това хранилище е многоезично разклонение на G4brym/email-explorer (лиценз MIT).

Интерфейсът е достъпен на 46 езика. Изберете своя горе вдясно; изборът се запомня в браузъра.
