# Email Explorer — Bahasa Melayu

Klien e-mel web yang berjalan sepenuhnya pada Cloudflare Workers.

Repositori ini ialah fork berbilang bahasa bagi G4brym/email-explorer (Lesen MIT).

Antara mukanya tersedia dalam 51 bahasa. Pilih bahasa anda di sebelah kanan atas; pilihan itu disimpan dalam pelayar.
