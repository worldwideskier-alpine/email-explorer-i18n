# Email Explorer — తెలుగు

పూర్తిగా Cloudflare Workers మీద నడిచే వెబ్‌మెయిల్.

ఈ రిపాజిటరీ G4brym/email-explorer (MIT లైసెన్స్) యొక్క బహుభాషా ఫోర్క్.

ఇంటర్‌ఫేస్ 73 భాషల్లో అందుబాటులో ఉంది. కుడి పైన ఉన్నదాని నుండి మీ భాషను ఎంచుకోండి; ఎంపిక బ్రౌజర్‌లో నిల్వ ఉంటుంది.
