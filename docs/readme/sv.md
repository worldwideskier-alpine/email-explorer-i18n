# Email Explorer — Svenska

En webbmejlklient som körs helt på Cloudflare Workers.

Det här arkivet är en flerspråkig fork av G4brym/email-explorer (MIT-licens).

Gränssnittet finns på 51 språk. Välj ditt uppe till höger; valet sparas i webbläsaren.
