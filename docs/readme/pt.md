# Email Explorer — Português

Um cliente de correio na web que funciona inteiramente sobre Cloudflare Workers.

Este repositório é uma bifurcação multilingue de G4brym/email-explorer (licença MIT).

A interface está disponível em 46 idiomas. Escolha o seu no canto superior direito; a escolha fica guardada no navegador.
