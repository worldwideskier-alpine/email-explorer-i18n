# Email Explorer — Ελληνικά

Ένα πρόγραμμα ηλεκτρονικού ταχυδρομείου στον ιστό, που τρέχει εξ ολοκλήρου πάνω στο Cloudflare Workers.

Αυτό το αποθετήριο είναι πολύγλωσσο fork του G4brym/email-explorer (άδεια MIT).

Η διεπαφή είναι διαθέσιμη σε 73 γλώσσες. Επιλέξτε τη δική σας πάνω δεξιά· η επιλογή αποθηκεύεται στο πρόγραμμα περιήγησης.
