# Email Explorer — Bosanski

Web klijent za e-poštu koji radi u cijelosti na Cloudflare Workers.

Ovaj repozitorij je višejezični fork projekta G4brym/email-explorer (MIT licenca).

Sučelje je dostupno na 72 jezika. Odaberite svoj gore desno; izbor se pamti u pregledniku.
