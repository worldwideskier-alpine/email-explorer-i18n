# Email Explorer — Беларуская

Вэб-кліент электроннай пошты, які працуе цалкам на Cloudflare Workers.

Гэты рэпазіторый — шматмоўны форк G4brym/email-explorer (ліцэнзія MIT).

Інтэрфейс даступны на 72 мовах. Выберыце сваю ў правым верхнім куце; выбар захоўваецца ў браўзеры.
