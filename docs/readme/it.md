# Email Explorer — Italiano

Un client di posta web che funziona interamente su Cloudflare Workers.

Questo repository è un fork multilingue di G4brym/email-explorer (licenza MIT).

L'interfaccia è disponibile in 73 lingue. Scegli la tua in alto a destra; la scelta viene ricordata nel browser.
