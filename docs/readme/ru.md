# Email Explorer — Русский

Веб-клиент электронной почты, работающий целиком на Cloudflare Workers.

Этот репозиторий — многоязычный форк G4brym/email-explorer (лицензия MIT).

Интерфейс доступен на 72 языках. Выберите свой в правом верхнем углу; выбор сохраняется в браузере.
