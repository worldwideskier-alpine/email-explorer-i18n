# Email Explorer — Română

Un client de e-mail web care rulează în întregime pe Cloudflare Workers.

Acest depozit este un fork multilingv al proiectului G4brym/email-explorer (licență MIT).

Interfața este disponibilă în 72 de limbi. Alegeți-o pe a dumneavoastră din dreapta sus; alegerea este reținută în browser.
