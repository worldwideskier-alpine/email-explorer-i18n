# Email Explorer — Norsk nynorsk

Ein nettbasert e-postklient som køyrer heilt på Cloudflare Workers.

Dette depotet er ein fleirspråkleg fork av G4brym/email-explorer (MIT-lisens).

Grensesnittet finst på 72 språk. Vel ditt oppe til høgre; valet blir hugsa i nettlesaren.

Fullstendig dokumentasjon (på japansk): [README](../../README.md)
