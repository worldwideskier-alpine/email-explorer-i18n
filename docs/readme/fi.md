# Email Explorer — Suomi

Verkkosähköpostiohjelma, joka toimii kokonaan Cloudflare Workersin päällä.

Tämä säilö on monikielinen haarautuma projektista G4brym/email-explorer (MIT-lisenssi).

Käyttöliittymä on saatavilla 72 kielellä. Valitse omasi oikeasta yläkulmasta; valinta muistetaan selaimessa.
