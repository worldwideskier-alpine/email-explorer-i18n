# Email Explorer — Српски

Веб клијент за е-пошту који ради у потпуности на Cloudflare Workers.

Ово спремиште је вишејезични форк пројекта G4brym/email-explorer (MIT лиценца).

Интерфејс је доступан на 72 језика. Изаберите свој горе десно; избор се памти у прегледачу.
