# Email Explorer — မြန်မာ

Cloudflare Workers ပေါ်တွင်သာ လုံးဝအလုပ်လုပ်သော ဝဘ်မေးလ်တစ်ခု။

ဤသိုလှောင်ခန်းသည် G4brym/email-explorer (MIT လိုင်စင်) ၏ ဘာသာစုံ fork ဖြစ်သည်။

အင်တာဖေ့စ်ကို ဘာသာစကား ၅၁ မျိုးဖြင့် အသုံးပြုနိုင်သည်။ ညာဘက်အပေါ်မှ သင့်ဘာသာစကားကို ရွေးပါ။ ရွေးချယ်မှုကို ဘရောက်ဇာတွင် မှတ်ထားပါသည်။
