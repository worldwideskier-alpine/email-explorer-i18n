# Email Explorer — Nederlands

Een webmailclient die volledig op Cloudflare Workers draait.

Deze repository is een meertalige fork van G4brym/email-explorer (MIT-licentie).

De interface is beschikbaar in 69 talen. Kies de uwe rechtsboven; uw keuze wordt in de browser onthouden.
