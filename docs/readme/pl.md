# Email Explorer — Polski

Klient poczty internetowej działający w całości na Cloudflare Workers.

To repozytorium jest wielojęzycznym forkiem G4brym/email-explorer (licencja MIT).

Interfejs jest dostępny w 51 językach. Wybierz swój w prawym górnym rogu; wybór zostaje zapamiętany w przeglądarce.
